# Brand derivative recipe

These files are derived deterministically from `public/assets/brand/temanusaha-mark.png` and `public/assets/illustrations/warung-dashboard-banner.png` so the established identity does not drift.

Run:

```powershell
python scripts/generate_brand_assets.py
```

Brand rules:

- Primary green: `#176b43`
- Ink: `#17211b`
- Off-white: `#f4f7f3`
- Saffron accent: `#e4a93f`
- Typeface: Segoe UI Bold / Regular
- Wordmark: `TemanUsaha AI`
- Social copy: `Asisten operasional warung dari percakapan ke tindakan.`

# Asset generation prompts

Generate the source assets one at a time with the built-in image generator.

1. `temanusaha-mark.md` -> `public/assets/brand/temanusaha-mark.png`
2. `warung-dashboard-banner.md` -> `public/assets/illustrations/warung-dashboard-banner.png`

The app icons are deterministic resized versions of the transparent brand mark, not separate generations.

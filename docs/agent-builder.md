# Custom GPT and agent builder path

Choose one client; do not create a client-specific backend path.

## Custom GPT

1. Open `GPTs/alfa.md` and complete the Builder fields in order.
2. Use the schema generated by Agent Setup for your own data.
3. Configure the token as an API key in the `X-Action-API-Key` header.
4. Test one read, then one mutation after explicit confirmation.

## Agent harness

```bash
node .claude/skills/asisten-pribadi/agent.mjs --help
node .claude/skills/asisten-pribadi/agent.mjs get_business_profile
```

Set `CONVEX_SITE_URL` and `AGENT_TOKEN` only in your local environment. Full
instructions and payload examples live in `.claude/skills/asisten-pribadi/SKILL.md`.

## MCP

The `/mcp` endpoint requires a deployment-level bearer key and a workspace
token. The bearer key opens the MCP server but does not select a tenant. Do not
weaken this two-credential model to shorten onboarding.
